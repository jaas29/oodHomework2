# OOD Homework 2 - TA reference solution

Reference solutions for office hours. Plain Java (17+), no build tool, no packages.
Written to match the style of the course's GitHub examples (OOD-NCF). One valid design, not the official key.

| Problem | Patterns | Run |
|---|---|---|
| [1 Hurricane Prediction](Problem1/README.md) | Template Method + Command | `sh Problem1/run.sh` |
| [2 Black Friday Shop](Problem2/README.md) | Composite + Observer | `sh Problem2/run.sh` |
| [3 Registration Form](Problem3/README.md) | Chain of Responsibility + Swing | `sh Problem3/run.sh` (GUI) or `--test` |

Run everything (Problem 3 in console mode): `sh run-all.sh`

Each folder has: source, `README.md` (patterns + why + resources), `sample-output.txt`, `uml.png` (+ `uml.dot` source).
Office-hours notes (common mistakes, hint ladder) live in the vault:
`2 - Classes/Fall 2026/OOD TA/OOD HW2 - Office Hours Reference.md`.

In IntelliJ, open one Problem folder at a time (every problem has a `Main` class).
